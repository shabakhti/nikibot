# 🤖 نیکی — دستیار هوش مصنوعی تلگرام

**یک دستیار هوش مصنوعی چندزبانه برای تلگرام، با قدرت Google Gemini و اجرا روی Cloudflare Workers.**

## ✨ نیکی چیست؟

نیکی یک همراه هوشمند برای تلگرام است. در چت خصوصی با او حرف بزنید یا به گروه اضافه‌اش کنید؛ او به **هر زبانی که بنویسید** جواب می‌دهد، زمینه‌ی گفتگو را به خاطر می‌سپارد، عکس و پیام صوتی را می‌فهمد، تصویر می‌کشد، حرف می‌زند، زبان و برنامه‌نویسی آموزش می‌دهد و آزمون برگزار می‌کند.

همه‌چیز — وب‌هوک، پنل ادمین، مینی‌اپ، API و لایه‌ی داده — در **یک فایل جاوااسکریپت** است که روی **حساب Cloudflare خودتان** اجرا می‌شود. سروری برای نگهداری نیست و برای یک استقرار کوچک روی پلن رایگان هزینه‌ای ندارد.

## 🧩 امکانات

### 💬 گفتگو
- چت مبتنی بر **Gemini** با چرخش خودکار بین حداکثر ۱۰ کلید API برای پخش سهمیه.
- **پنج شخصیت** (`/mode 1–5`): عادی، تحلیلی، پرامپت سفارشی، معلم انگلیسی، برنامه‌نویسی.
- **حافظه‌ی کوتاه‌مدت** برای هر چت و **حافظه‌ی بلندمدت** (آرشیو و واقعیت‌های ماندگار درباره‌ی هر کاربر).
- **جست‌وجوی زنده‌ی وب** (Google Search): بگویید «جست‌وجو کن …» یا آخرین اخبار، آب‌وهوا، قیمت و نتایج را بپرسید. به‌صورت پیش‌فرض روشن است و سقف روزانه دارد؛ از *Config ← Global features* یا برای هر چت جداگانه قابل خاموش‌کردن است.
- فهم **تصویر، پیام صوتی و ریپلای**.
- **ری‌اکشن ایموجی** و رفتار هوشمند در گروه (با صدا زدن نام، یا همه‌چیز با `/alwayson`).

### 🎨 رسانه
- **ساخت تصویر** (Flux-1-schnell روی Workers AI) تا ۴ تصویر در هر درخواست.
- **پاسخ صوتی** (متن به گفتار) با موتور و صداهای قابل انتخاب.
- **گفتار به متن** (Whisper) برای پیام‌های صوتی.

### 🎓 یادگیری و سرگرمی
- **معلم زبان** و **معلم برنامه‌نویسی** با جلسه‌های گام‌به‌گام، تمرین و مرور لغت با تکرار فاصله‌دار.
- **آزمون‌های اشتراک‌پذیر**، فلش‌کارت لغت، آمار، جدول برترین‌ها و گواهی.
- **تماس صوتی** داخل مینی‌اپ.

### 👥 گروه و جامعه
- فعال‌سازی گروه با تأیید ادمین.
- سلسله‌مراتب: **کاربر ← ادمین ← لیدر ← سوپر ادمین**.
- مدیریت: سکوت، بن، پاک‌سازی، پین، قفل گروه.
- **لینک دعوت** با پاداش معرفی.

### 💳 محدودیت و فروش
- سقف **روزانه و کل** برای هر کاربر و گروه (پیام، تصویر، صدا).
- **بسته‌ها** (پکیج زمان‌دار) که می‌توانید با **Telegram Stars** بفروشید یا دستی هدیه دهید.
- حالت تعمیر، پیام خوش‌آمد، سقف روزانه‌ی هر چت.

### 🛠 مدیریت
- **پنل وب** دوزبانه (فارسی/انگلیسی) با راهنمای داخلی: گروه‌ها، کاربران، پیام همگانی، کلیدها، بسته‌ها، تنظیمات، قابلیت‌ها و لاگ.
- **موتور پیام همگانی** قابل ازسرگیری (صف، توقف، ادامه، لغو).
- **REST API عمومی** (`/api/chat`، `/api/tts`، `/api/stt`) با محدودیت، انقضا و CORS برای هر کلید.

### 🔐 حریم خصوصی از پایه
- **هیچ نمایشگر چت یا جست‌وجوی پیام** در پنل یا دستورها وجود ندارد.
- لاگ‌ها فقط رویداد دارند، نه متن پیام.
- کاربر هر زمان می‌تواند حافظه‌ی خودش را پاک کند.

### 🌍 زبان
| بخش | پیش‌فرض | گزینه‌ها |
|---|---|---|
| پاسخ‌های هوش مصنوعی | **خودکار** — به زبانی که کاربر می‌نویسد (در صورت نامشخص بودن انگلیسی) | همیشه انگلیسی یا همیشه فارسی — در Setup یا *Config ← Reply language* |
| پیام‌های ثابت ربات (راهنما، محدودیت، خطا) | انگلیسی | فارسی — `/lang fa` |
| پنل ادمین و راهنما | انگلیسی | فارسی — دکمه‌ی 🌐 |
| مینی‌اپ | انگلیسی | فارسی (خودکار اگر زبان تلگرام کاربر فارسی باشد) |
| نصب‌کننده | انگلیسی (`/`) | فارسی (`/fa`) |

## 🚀 نصب آسان (پیشنهادی)

نصب‌کننده در حدود یک دقیقه نیکی را روی **حساب Cloudflare خودتان** مستقر می‌کند — بدون خط فرمان.

> 🔗 **نصب‌کننده:** **https://wizard.nikibot.workers.dev/fa**

### مرحله‌به‌مرحله

1. **نصب‌کننده را باز کنید** — <https://wizard.nikibot.workers.dev/fa> (فارسی) یا <https://wizard.nikibot.workers.dev/> (انگلیسی).
2. **یک توکن API در Cloudflare بسازید.** روی **Create a token** در صفحه‌ی نصب‌کننده بزنید؛ فقط دسترسی‌های لازم از قبل انتخاب شده‌اند:
   - Workers Scripts — Edit
   - Workers KV Storage — Edit
   - D1 — Edit
   - Account Settings — Read

   سپس **Continue to summary ← Create Token** را بزنید و **توکن را کپی کنید**.
3. **توکن را در نصب‌کننده بچسبانید**، در صورت تمایل نام پروژه را انتخاب کنید و **Install** را بزنید.
4. نصب‌کننده روی حساب شما این کارها را انجام می‌دهد:
   - ساخت **پایگاه D1** (`NIKI_DB`) و **فضای KV** (`NIKI_KV`)،
   - فعال‌سازی **Workers AI** (`AI`)،
   - آپلود کد ربات،
   - فعال‌کردن آدرس `workers.dev`،
   - افزودن **کرون هر ۱ دقیقه** (برای پیام همگانی و کارهای زمان‌بندی‌شده).
5. در پایان دو لینک می‌گیرید:
   - **آدرس سرویس** — `https://<name>.<subdomain>.workers.dev`
   - **پنل ادمین** — `https://<name>.<subdomain>.workers.dev/admin` (محرمانه نگه دارید!)
6. **حالا می‌توانید توکن API را از داشبورد Cloudflare حذف کنید.**
7. به [راه‌اندازی اولیه](#-راه‌اندازی-اولیه) بروید.

> 🔒 **توکنم امن است؟** توکن فقط در همان درخواست نصب برای صحبت با API کلادفلر استفاده می‌شود؛ ذخیره یا لاگ نمی‌شود. اگر نمی‌خواهید توکن را به صفحه‌ی شخص ثالث بدهید، از [نصب دستی](#-نصب-دستی) استفاده کنید؛ حدود ۱۰ دقیقه طول می‌کشد و نتیجه یکسان است.

> ⚠️ **پنل در اولین اجرا رمز ندارد.** بلافاصله پس از نصب آن را باز کنید و رمز بگذارید. تا آن زمان هر کسی که آدرس Worker را بداند می‌تواند پنل را باز کند.

### به‌روزرسانی با نصب‌کننده
نصب‌کننده را دوباره با **همان نام پروژه** اجرا کنید. دیتابیس، KV و secretها حفظ می‌شوند و فقط کد جایگزین می‌شود.

## 🧰 نصب دستی

کنترل کامل می‌خواهید یا از خط فرمان / CI استقرار می‌دهید؟ این مراحل را دنبال کنید.

### ۱. دریافت کد
</div>

```bash
git clone https://github.com/YOUR_USERNAME/niki-bot.git
cd niki-bot
npm install -g wrangler        # or: npx wrangler ...
wrangler login
```

<div dir="rtl">

### ۲. ساخت فضای ذخیره‌سازی
</div>

```bash
# D1 database
wrangler d1 create niki-db
# → copy the printed "database_id"

# KV namespace
wrangler kv namespace create NIKI_KV
# → copy the printed "id"
```

<div dir="rtl">

### ۳. ساخت `wrangler.toml`
</div>

```toml
name = "niki-bot"
main = "bot.js"
compatibility_date = "2025-01-01"

[ai]
binding = "AI"

[[d1_databases]]
binding = "NIKI_DB"
database_name = "niki-db"
database_id = "PASTE_D1_DATABASE_ID"

[[kv_namespaces]]
binding = "NIKI_KV"
id = "PASTE_KV_NAMESPACE_ID"

[triggers]
crons = ["* * * * *"]

[vars]
# Comma-separated numeric Telegram IDs of the owner(s)
SUPER_ADMIN_IDS = "123456789"
```

<div dir="rtl">

> ℹ️ نام بایندینگ‌ها **باید** دقیقاً `NIKI_DB`، `NIKI_KV` و `AI` باشد. جدول‌های دیتابیس در اولین درخواست خودکار ساخته می‌شوند.

### ۴. افزودن Secretها
</div>

```bash
wrangler secret put TELEGRAM_BOT_TOKEN        # from @BotFather
wrangler secret put GEMINI_API_KEY_1          # your first Gemini key
# optional: GEMINI_API_KEY_2 … GEMINI_API_KEY_10
wrangler secret put TELEGRAM_WEBHOOK_SECRET   # optional but recommended: any long random string
```

<div dir="rtl">

> توکن ربات و کلیدهای Gemini را می‌توانید بعداً از پنل ادمین هم وارد کنید.

### ۵. استقرار
</div>

```bash
wrangler deploy
```

<div dir="rtl">

Wrangler آدرس Worker را چاپ می‌کند، مثلاً `https://niki-bot.<subdomain>.workers.dev`.

### ۶. ثبت وب‌هوک تلگرام

**روش الف — از پنل (آسان‌تر):** `https://<آدرس-worker>/admin` را باز کنید و کارت Setup را کامل کنید؛ پنل وب‌هوک را ثبت می‌کند.

**روش ب — دستی:**
</div>

```bash
curl "https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook" \
  -d "url=https://<your-worker-url>/" \
  -d "secret_token=<TELEGRAM_WEBHOOK_SECRET>" \
  -d 'allowed_updates=["message","edited_message","callback_query","pre_checkout_query"]'
```

<div dir="rtl">

(اگر `TELEGRAM_WEBHOOK_SECRET` نگذاشته‌اید، `secret_token` را حذف کنید.)

### ۷. بررسی
</div>

```bash
curl "https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/getWebhookInfo"
```

<div dir="rtl">

مقدار `url` باید آدرس Worker شما باشد و `last_error_message` خالی. سپس `/start` را به ربات بفرستید.

## 🧭 راه‌اندازی اولیه

پنل ادمین را در `https://<آدرس-worker>/admin` باز کنید.

1. **نوار Setup بالای صفحه را کامل کنید** (موارد باقی‌مانده را نشان می‌دهد):
   - 🤖 **توکن ربات تلگرام** (یوزرنیم ربات خودکار تشخیص داده می‌شود)
   - 🌍 **زبان ربات** — *خودکار* (پیش‌فرض)، *انگلیسی* یا *فارسی*: زبانی که هوش مصنوعی با آن حرف می‌زند و پرامپت سیستم مدل با آن تطبیق پیدا می‌کند. بعداً از *Config ← Reply language* قابل تغییر است.
   - 🧬 **کلید Gemini**
   - 🔐 **رمز پنل** — *حتماً همین الان بگذارید.*

   کارت Setup وب‌هوک تلگرام را هم برایتان ثبت می‌کند.
2. **خودتان را سوپر ادمین کنید:** *Config ← Super admins* ← آیدی عددی تلگرامتان (یا متغیر `SUPER_ADMIN_IDS`).
3. **محدودیت‌ها را تنظیم کنید:** *Config ← New-user limits / Group limits*.
4. *(اختیاری)* پرامپت‌ها و شخصیت‌ها، نام ربات، متن‌های خوش‌آمد و موتور صدا را ویرایش کنید.
5. تب **📖 Guide** را باز کنید — راهنمای کامل و دوزبانه‌ی همه‌ی بخش‌های پنل، با لینک مینی‌اپ آماده‌ی کپی.
6. **تست کنید:** به ربات پیام بدهید، سپس آن را به گروه اضافه کنید و `/init` بزنید.

### فعال‌سازی گروه
1. ربات را به گروه اضافه کنید.
2. سازنده‌ی گروه `/init` را می‌فرستد. درخواست در **Overview ← Requests** ظاهر می‌شود (و سوپر ادمین‌ها در چت خصوصی خبردار می‌شوند).
3. سوپر ادمین **Approve** را می‌زند و ربات در آن گروه فعال می‌شود.

تا زمانی که گروه تأیید نشده، ربات فقط به فرایند فعال‌سازی پاسخ می‌دهد.

## ⚙️ روش کار
</div>

```
Telegram ──► Cloudflare Worker (this file) ──► Google Gemini (chat, vision, TTS)
                 │   │   │                └──► Workers AI (Flux images, Whisper STT)
                 │   │   └── KV  (caches, sessions, rate limits, dedup)
                 │   └────── D1  (users, groups, limits, memory, packages, logs)
                 └────────── Cron (every minute: broadcasts & scheduled jobs)
```

<div dir="rtl">

- **وب‌هوک** — تلگرام آپدیت‌ها را به `/` می‌فرستد. اگر `TELEGRAM_WEBHOOK_SECRET` تنظیم باشد هدر `X-Telegram-Bot-Api-Secret-Token` بررسی می‌شود و آپدیت‌های تکراری با `update_id` حذف می‌شوند.
- **مسیرها**

  | مسیر | کاربرد |
  |---|---|
  | `/` (POST) | وب‌هوک تلگرام |
  | `/admin` | پنل ادمین |
  | `/app` | مینی‌اپ تلگرام |
  | `/api/chat` · `/api/tts` · `/api/stt` | REST API عمومی |

- **چرخش کلید** — کلیدهای Gemini به‌نوبت استفاده می‌شوند تا یک کلید تمام‌شده ربات را از کار نیندازد.
- **دسترسی‌ها** — `USER (0) < ADMIN (1) < LEADER (2) < SUPER (3)`. سوپر ادمین فقط با آیدی عددی تعریف می‌شود.
- **محدودیت‌ها** — سقف روزانه و کل برای پیام / تصویر / صدا، برای هر کاربر و گروه؛ بسته‌ها و پاداش دعوت به آن اضافه می‌کنند.

## ⌨️ دستورهای ربات

دستورها در چت خصوصی و گروه کار می‌کنند مگر خلاف آن گفته شود. در **چت خصوصی** شما ادمین گفتگوی خودتان هستید و دستورهای حافظه و شخصیت در دسترس است.

### 👤 همه

| دستور | توضیح |
|---|---|
| `/start` | شروع و پیام خوش‌آمد. |
| `/help` | راهنمای مناسب نوع چت. |
| `/app` | باز کردن **مینی‌اپ** (چت خصوصی). |
| `/lang fa\|en` | زبان پیام‌های ثابت ربات (راهنما، محدودیت، خطا). |
| `/setname <نام>` | نامی که ربات شما را با آن صدا می‌زند. |
| `/myperm` | سطح دسترسی شما. |
| `/mylimit` | محدودیت‌های باقی‌مانده. |
| `/stats` | آمار مصرف شما. |
| `/image <توضیح>` | ساخت یک تصویر. |
| `/image <n> <توضیح>` | ساخت `n` تصویر (حداکثر ۴). |
| `/invite` · `/mylink` | لینک دعوت شخصی (پاداش بگیرید). |
| `/myfriends` · `/friends` | فهرست دوستان دعوت‌شده. |
| `/packages` | مشاهده / خرید بسته‌ها. |

### 🧠 شخصیت و حافظه (چت خصوصی یا ادمین‌های گروه)

| دستور | توضیح |
|---|---|
| `/mode 1\|2\|3\|4\|5` | **1** عادی · **2** تحلیلی · **3** پرامپت سفارشی · **4** معلم انگلیسی · **5** برنامه‌نویسی. بدون عدد، منوی انتخاب باز می‌شود. |
| `/reset` | پاک‌کردن حافظه‌ی کوتاه‌مدت این چت. |
| `/memstats` | آمار حافظه‌ی بلندمدت. |
| `/memclear` | پاک‌کردن حافظه‌ی بلندمدت. |
| `/alwayson` | روشن/خاموش «پاسخ به همه‌ی پیام‌ها». |
| `/histclear` | پاک‌کردن تاریخچه و آرشیو این چت. |

### 🛡 ادمین‌های گروه

| دستور | توضیح |
|---|---|
| `/init` | *(سازنده‌ی گروه)* درخواست فعال‌سازی گروه. |
| `/silent` | سکوت/فعال‌کردن نیکی در گروه. |
| `/lockdown` | حالت قفل گروه. |

## 📱 مینی‌اپ تلگرام

یک اپ گرافیکی شبیه ChatGPT که **داخل تلگرام** و در `/app` باز می‌شود.

**چگونه باز کنیم**
- در چت خصوصی `/app` را بفرستید و دکمه‌ی **App** را بزنید، یا
- لینک `https://t.me/<یوزرنیم_ربات>?start=app` را به اشتراک بگذارید (در *Admin ← 📖 Guide ← Mini App* آماده است).

**تنظیم اختیاری BotFather** (دکمه‌ی منوی دائمی):
`@BotFather ← /mybots ← ربات شما ← Bot Settings ← Menu Button ← Configure menu button` و آدرس `https://<آدرس-worker>/app` را بدهید.
برای لینک مستقیم `t.me/<bot>/<app>` از `/newapp` با همین آدرس استفاده کنید.

**بخش‌ها** (هرکدام در *Admin ← Features ← Mini App* قابل خاموش‌کردن است)

| | بخش |
|---|---|
| 💬 | چت عادی (همگام با تلگرام) |
| 🧑‍💻 | چت برنامه‌نویس |
| 🎓 | یادگیری زبان · یادگیری برنامه‌نویسی |
| 🧠 | آزمون‌ها (اشتراک‌پذیر) |
| 🗂️ | فلش‌کارت لغت (تکرار فاصله‌دار) |
| 📊 | آمار و جدول برترین‌ها |
| 🎙️ | تماس صوتی |
| 🎭 | شخصی‌سازی (نام و پرامپت) |
| 🏅 | گواهی یادگیری |
| 🖼️ | ساخت تصویر |
| ✏️ | تغییر نام و حذف چت‌ها |

## 🔌 API خارجی

از مغز نیکی در سایت، اپ یا ربات خودتان استفاده کنید — بدون نیاز به تلگرام. در **Admin ← 🔑 API Keys** کلید بسازید (کلید فقط یک‌بار نمایش داده می‌شود).
</div>

```bash
curl -X POST "https://<your-worker-url>/api/chat" \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"userId":"42","message":"Hello!"}'
```

```json
{"ok":true,"reply":"Hi! How can I help?","usage":{"msgUsed":3,"msgLimit":500,"imgUsed":0,"imgLimit":20}}
```

<div dir="rtl">

| Endpoint | کاربرد | Body |
|---|---|---|
| `POST /api/chat` | چت: ورودی متن/تصویر/صدا ← خروجی متن (و اختیاری تصویر/صدا) | `{"userId","message", …}` |
| `POST /api/tts` | متن ← گفتار | `{"text":"…","lang":"auto"}` |
| `POST /api/stt` | گفتار ← متن | `{"audioBase64":"…"}` |

**نکته‌ها**
- **احراز هویت:** `X-API-Key: KEY` (یا `Authorization: Bearer KEY` یا `?api_key=KEY`).
- **حافظه و محدودیت برای هر کاربر:** یک `userId` ثابت بفرستید تا هر کاربر نهایی حافظه، پرامپت سیستم و سهمیه‌ی خودش را داشته باشد.
- **فیلدهای اختیاری:** `imageBase64`/`imageMime`، `audioBase64`/`audioMime`، `transcribeAudio`، `voiceReply`، `systemPrompt`، `setSystemPrompt`، `memory`، `setLimits`/`addLimits`.
- **گزارش کل کلید:** `{"userId":"admin"}` مصرف کل، تعداد کاربر و انقضا را رایگان برمی‌گرداند.
- **خطاها:** `401` کلید نامعتبر · `403` غیرفعال/منقضی · `400` بدنه‌ی نامعتبر · `413` حجم زیاد · `429` رسیدن به سقف · `502/500` مشکل مدل (سهمیه برگردانده می‌شود).

مرجع کامل در پنل، **API Keys ← 📖 API guide** است.

> 🔒 API را از **سرور خودتان** صدا بزنید. کلیدی که در صفحه‌ی عمومی یا اپ موبایل باشد قابل کپی است.

## 🔐 حریم خصوصی و امنیت

**حریم خصوصی پیام‌ها**
- پنل ادمین و دستورهای ربات **هیچ راهی برای خواندن یا جست‌وجوی گفتگوی کاربران** ندارند؛ نه نمایشگر چت، نه جست‌وجوی آرشیو، نه خروجی.
- لاگ‌ها رویداد ثبت می‌کنند (مثل «گروه تأیید شد») و هرگز متن پیام را نه.
- کاربران با `/reset`، `/memclear` و `/histclear` زمینه‌ی خود را پاک می‌کنند؛ ادمین‌ها از *Config ← Clear history*.
- زمینه‌ی گفتگو برای حافظه‌ی ربات هنوز در D1 شما ذخیره می‌شود. هر کسی که به حساب Cloudflare شما دسترسی داشته باشد از نظر فنی می‌تواند آن را بخواند — **شما مسئول داده‌ها هستید**؛ به کاربران بگویید چه چیزی ذخیره می‌کنید.
- پیام‌ها برای تولید پاسخ به Google Gemini فرستاده می‌شوند و شرایط گوگل بر آن محتوا حاکم است.

**امنیت عملیاتی**
- بلافاصله پس از اولین اجرا **رمز پنل** بگذارید.
- سوپر ادمین‌ها فقط با **آیدی عددی** شناسایی می‌شوند (یوزرنیم قابل تغییر و جعل است).
- `TELEGRAM_WEBHOOK_SECRET` را تنظیم کنید تا فقط تلگرام بتواند وب‌هوک را صدا بزند.
- توکن‌ها و کلیدها را در **Secretهای** Cloudflare نگه دارید و هرگز commit نکنید.
- برای هر اپ یک کلید API با محدودیت و انقضا بسازید؛ کلید لو‌رفته را فوراً حذف کنید.
- مینی‌اپ `initData` امضاشده‌ی تلگرام را سمت سرور تأیید می‌کند.

## ❓ پرسش‌های متداول

**هزینه دارد؟** یک استقرار کوچک در پلن رایگان Cloudflare جا می‌شود و Gemini هم پلن رایگان دارد. مصرف سنگین ممکن است به پلن پولی نیاز داشته باشد.

**فقط برای فارسی‌زبان‌هاست؟** نه — پروژه چندزبانه است. پیش‌فرض انگلیسی است و فارسی ترجمه‌ی کامل و اختیاری است. هوش مصنوعی به هر زبانی که کاربر بنویسد جواب می‌دهد.

**چطور زبان را عوض کنم؟** زبان گفتگوی هوش مصنوعی را در Setup یا *Config ← Reply language* (خودکار / انگلیسی / فارسی) تعیین کنید. زبان پیام‌های ثابت ربات برای هر چت با `/lang en` یا `/lang fa` عوض می‌شود.

**می‌توانم اسم و شخصیت ربات را عوض کنم؟** بله — *Config ← Bot name* و *Config ← Default prompts*.

**می‌توانم چند ربات داشته باشم؟** بله. برای هر ربات یک‌بار استقرار بدهید (هرکدام D1/KV خودش را دارد)، مثلاً با اجرای نصب‌کننده با نام‌های مختلف.

**می‌توانم دسترسی بفروشم؟** بله — **بسته‌ها** بسازید و خرید با Telegram Stars را فعال کنید، یا از پنل سهمیه هدیه دهید.

**کد باز است؟** ربات یک ماژول جاوااسکریپت خوانا و تک‌فایلی است؛ بخش‌ها با `§ N` علامت‌گذاری شده و فهرست مطالب در ابتدای فایل است.
